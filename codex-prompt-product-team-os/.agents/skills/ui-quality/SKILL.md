---
name: ui-quality
description: Design or review a user-facing flow for complete states, accessibility, responsive behavior, design-system reuse, trustworthy content, and safe prompt previews. Use for frontend UX work.
---

1. Define persona, goal, entry point, and success state.
2. Map loading, empty, error, success, permission, expired entitlement, unsupported model, and retry states.
3. Reuse existing components and tokens.
4. Verify keyboard navigation, focus, labels, contrast, screen-reader semantics, and responsive layout.
5. Make product type, inputs, outcome, compatibility, limitations, license, and version understandable.
6. Keep full paid content out of public/client-visible previews for unauthorized users.
7. Define UI acceptance criteria and focused tests.
