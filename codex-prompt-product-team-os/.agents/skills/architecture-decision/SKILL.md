---
name: architecture-decision
description: Produce an Architecture Decision Record for a material technical choice, including invariants, options, trade-offs, contracts, migration, rollback, security, observability, and ownership. Do not use for trivial implementation details.
---

1. Read the Task Contract and current architecture evidence.
2. State constraints, quality attributes, and invariants.
3. Map affected domains and trust boundaries.
4. Present at least two viable options for material choices.
5. Evaluate complexity, reliability, security, privacy, migration, cost, and future evolution.
6. Choose the smallest adequate option and state rejected alternatives.
7. Define API/data contracts, compatibility, failure handling, observability, migration/backfill, and rollback.
8. Record owners and required approvals.
9. Write the ADR using `.ai/templates/ADR.md`.
