---
name: prompt-product-design
description: Design a sellable prompt, prompt pack, workflow stack, assistant blueprint, or agent template with schema, variables, compatibility, preview protection, license, versioning, examples, and eval requirements. Do not use for generic copywriting.
---

1. Select canonical product type: `single_prompt`, `prompt_pack`, `workflow_stack`, `assistant_blueprint`, or `agent_template`.
2. Define audience, job-to-be-done, outcome, prerequisites, limitations, and success criteria.
3. Define private content separately from public preview/redaction.
4. Specify variables: type, required, validation, default, examples, and sensitivity.
5. Specify model/provider compatibility, tool/knowledge dependencies, and known failure modes.
6. Define version, changelog, compatibility, deprecation, and customer entitlement update policy.
7. Define license and permitted usage; flag legal decisions for human approval.
8. Add examples, anti-examples, usage instructions, and privacy warnings.
9. Create or reference an evaluation plan before production readiness.
10. Update the domain spec without leaking paid content into public fixtures or analytics.
