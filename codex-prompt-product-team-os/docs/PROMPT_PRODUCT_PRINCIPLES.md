# Prompt product principles

## Separate these concepts

- Prompt definition: private versioned content and variables.
- Commercial product: title, positioning, price, merchandising, and availability.
- Version: immutable content release.
- Preview: separate redacted public artifact.
- License: permitted use.
- Entitlement: who may access which version and updates.
- Evaluation: evidence that the product meets its quality claim.
- Usage artifact: a buyer's private variable values, run history, or customized fork.

## Product evolution

The domain should support:

1. Single prompt.
2. Prompt pack.
3. Workflow/stack with ordered steps and handoff state.
4. Assistant blueprint with instructions, knowledge, tools, and operating rules.
5. Agent template with permissions, memory, tools, handoffs, hooks, and evals.

## Non-negotiable invariants

- Unauthorized users never receive full private prompt content.
- A sold prompt version is immutable; corrections create a new version.
- Entitlement update behavior is explicit.
- Public preview is not generated by slicing the full prompt on the client.
- Analytics never contains full paid content, secrets, or raw sensitive user input.
- Quality claims are tied to eval evidence and known limitations.
- License and compatibility are visible before purchase.
