# Definition of Done

A task is done only when all applicable items are complete:

- [ ] Every acceptance criterion has evidence.
- [ ] Code is within approved scope and paths; unrelated changes are removed.
- [ ] Architecture and domain invariants remain valid or approved ADRs are updated.
- [ ] Prompt-product spec/version/eval artifacts are updated when behavior changes.
- [ ] Loading, empty, error, success, permission, and responsive/accessibility states are covered.
- [ ] Format, lint, typecheck, unit, integration, E2E, migration, and manual checks are run or skips are approved.
- [ ] Authorization, entitlement, payment idempotency, privacy, prompt leakage, and abuse paths are reviewed when applicable.
- [ ] Migration/backfill/rollback and compatibility are verified.
- [ ] Analytics, observability, docs, and support notes are updated.
- [ ] No unresolved P0/P1 findings.
- [ ] Structured handoff identifies residual risk and next owner.
- [ ] Product HQ accepts the outcome; Founder approves production release.
